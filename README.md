# TypeScript

Este repositório reúne meus estudos em TypeScript realizados na Rocketseat

<!--
COMANDOS TYPESCRIPT

Compilar os arquivos configurados no tsconfig.json:
tsc

Compilar usando explicitamente o tsconfig.json:
tsc --project tsconfig.json

Compilar novamente sempre que um arquivo mudar:
tsc --watch

Verificar erros de TypeScript sem gerar arquivos JavaScript:
tsc --noEmit

Observação: para incluir um arquivo novo na compilação com "tsc", adicione-o
à propriedade "include" do tsconfig.json.
-->
